# 만약 당신이 범죄자라면… · 저택 데모

첨부 타이틀 이미지와 저택 도면을 사용한 pico2d 잠입·퍼즐 데모입니다.
현관, 연회장, 주방, 복도, 서재, 금고실을 각각 한 화면에 표시합니다.
목적지가 써 있는 문 쪽으로 걸어가면 화면이 전환됩니다. 각 방의 벽과 주요 가구에는 이동 충돌을 적용했습니다.

## Windows에서 실행

Python 3.10 이상을 권장합니다. 압축을 푼 뒤 `main.py`가 있는 폴더에서 명령 프롬프트를 열고 다음을 실행합니다.

```bat
py -m pip install -r requirements.txt
py main.py
```

한글 표시에는 시스템의 맑은 고딕 또는 굴림을 사용합니다. Linux는 나눔고딕 또는 Noto Sans CJK를 지원합니다.

## 조작

| 키 | 기능 |
|---|---|
| Space / Enter | 타이틀에서 시작 |
| WASD / 방향키 | 걷기와 문 통과 |
| E | 가까운 대상과 대화·조사 또는 물건 줍기 |
| Q | 든 물건 내려놓기 |
| 숫자키 / Enter | 금고 암호 입력과 확인 |
| Esc | 암호 입력 취소 또는 게임 종료 |
| R | 결과 화면에서 다시 시작 |

보석을 확보한 뒤 현관의 ‘저택 밖’ 출구로 나가는 것이 목표입니다.
파티 총무에게서 단서를 얻어 금고를 여는 루트와, 세 NPC 관련 사전 준비를 마친 후
주인을 협박하는 루트가 있습니다. 금고 암호와 대사는 데모 설정입니다.
IT 전문가가 보안을 점검할 때는 금고실 출입으로 의심도가 오르지 않습니다.
칼이나 보석을 목격하면 기존처럼 의심도가 오릅니다.

## 코드

- `rooms.py`: 방별 이미지 좌표와 벽·가구·문 영역
- `stage.py`: 충돌, 문 전환, 목격과 강도 결과 판정
- `play_mode.py`: 방별 캐릭터와 상호작용, HUD, 탈출
- `game_world.py`, `game_framework.py`: 객체 갱신과 게임 모드 전환

`python tests/headless_verify.py`로 스프라이트와 기본 게임 로직을 점검할 수 있습니다.


## 현장 조사 자료와 사건 이후 현장

현관, 주방, 서재에 놓인 종이 묶음을 E로 주우면 현장 조사 자료를 2개씩 얻습니다.
자료는 손에 든 물건과 별도로 보관합니다. H를 누르면 현재 방의 사건 이후 현장을 조사합니다.
처음 확인하는 방은 자료 1개를 소비하고, 이미 열린 방은 추가 소비 없이 확인할 수 있습니다.

조사 화면에서는 탐정을 이동해 흔적 가까이에서 E를 누릅니다.
현재의 흔적은 복도의 빈 커피잔과 약 포장지, 연회장의 촬영 기록, 금고실의 보안 점검 기록,
주방의 비어 있는 칼자리, 서재의 기념일 메모, 현관의 출입 기록입니다.
힌트를 확인해도 과거 재현의 준비 조건은 플레이어가 직접 해결해야 합니다.

H 또는 Esc로 조사에서 돌아옵니다. 조사와 수첩 화면에서는 재현의 NPC, 의심도,
타이머가 멈춥니다. N으로 수첩을 열고 방향키로 발견한 단서를 넘깁니다.
다시 시작하면 자료와 수첩도 초기화됩니다.


## 선수의 감시 멈추기

연회장의 커피와 서재의 수면제를 찾습니다. 한쪽을 E로 든 상태에서
다른 쪽에 접근해 E를 누르면 수면제가 든 커피로 조합됩니다.
획득 순서는 자유롭습니다. 복도의 선수에게 E로 건네면 잠들고 감시와 강도 개입이 멈춥니다.
프로틴, 일반 커피, 수면제 단독으로는 선수를 무력화할 수 없습니다.
조합한 커피도 Q로 내려놓고 E로 다시 주울 수 있습니다.

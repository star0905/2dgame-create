# 만약 당신이 범죄자라면… · 저택 데모

첨부 타이틀 이미지와 저택 도면을 사용한 pico2d 잠입·퍼즐 데모입니다.
현관, 연회장, 주방, 복도, 서재, 금고실을 각각 한 화면에 표시합니다.
목적지가 써 있는 문 쪽으로 걸어가면 화면이 전환됩니다. 각 방의 벽과 주요 가구에는 이동 충돌을 적용했습니다.

## Windows에서 실행

Python 3.10 이상을 권장합니다. 압축을 푼 뒤 `main.py`가 있는 폴더에서 명령 프롬프트를 열고 다음을 실행합니다.

```bat
py -m pip install -r requirements.txt
py main.py
```

한글 표시에는 시스템의 맑은 고딕 또는 굴림을 사용합니다. Linux는 나눔고딕 또는 Noto Sans CJK를 지원합니다.

## 조작

| 키 | 기능 |
|---|---|
| Space / Enter | 타이틀에서 시작 |
| WASD / 방향키 | 걷기와 문 통과 |
| E | 가까운 대상과 대화·조사 또는 물건 줍기 |
| Q | 든 물건 내려놓기 |
| 숫자키 / Enter | 금고 암호 입력과 확인 |
| Esc | 암호 입력 취소 또는 게임 종료 |
| R | 결과 화면에서 다시 시작 |

보석을 확보한 뒤 현관의 ‘저택 밖’ 출구로 나가는 것이 목표입니다.
파티 총무에게서 단서를 얻어 금고를 여는 루트와, 세 NPC 관련 사전 준비를 마친 후
주인을 협박하는 루트가 있습니다. 금고 암호와 대사는 데모 설정입니다.
IT 전문가가 보안을 점검할 때는 금고실 출입으로 의심도가 오르지 않습니다.
칼이나 보석을 목격하면 기존처럼 의심도가 오릅니다.

## 코드

- `rooms.py`: 방별 이미지 좌표와 벽·가구·문 영역
- `stage.py`: 충돌, 문 전환, 목격과 강도 결과 판정
- `play_mode.py`: 방별 캐릭터와 상호작용, HUD, 탈출
- `game_world.py`, `game_framework.py`: 객체 갱신과 게임 모드 전환

`python tests/headless_verify.py`로 스프라이트와 기본 게임 로직을 점검할 수 있습니다.


## 현장 조사 자료와 사건 이후 현장

종이 묶음을 E로 주우면 자료 1개씩, 총 3개를 얻습니다.
모든 방에서 H를 눌러 사건 이후 현장을 조사할 수 있습니다. 처음 여는 방에서는 자료 1개를 사용하며,
이미 연 방은 무료로 다시 볼 수 있습니다. 어느 방을 먼저 조사할지 직접 선택합니다.
흔적은 당시의 작은 변화나 증언으로 제시하며, 힌트 위치 목록은 미리 안내하지 않습니다.

조사 중에는 재현의 NPC와 의심도 타이머가 멈춥니다.
E로 흔적을 조사하고 H 또는 Esc로 복귀합니다. N으로 수첩을 열어 방향키로 기록을 넘깁니다.
다시 시작하면 자료와 수첩도 초기화됩니다.

사진작가는 대화 후 촬영을 멈추고 서재로 이동해 카메라 장비를 점검합니다.

## 방 배치

연회장의 식탁과 의자는 원래 크기의 78%로 함께 표시하고 충돌도 같은 비율로 적용합니다.
보안 전문가 이도현은 서재의 책상 오른쪽에서 만날 수 있습니다.
주방 조리대 위의 칼, 서재 책상 위의 수면제, 연회장 음료대 위의 커피는
가구 옆으로 접근한 뒤 E로 집습니다.

## 선수의 감시 멈추기

연회장의 커피와 서재의 수면제를 찾습니다. 한쪽을 E로 든 상태에서
다른 쪽에 접근해 E를 누르면 수면제가 든 커피로 조합됩니다.
획득 순서는 자유롭습니다. 복도의 선수에게 E로 건네면 잠들고 감시와 강도 개입이 멈춥니다.
프로틴, 일반 커피, 수면제 단독으로는 선수를 무력화할 수 없습니다.
조합한 커피도 Q로 내려놓고 E로 다시 주울 수 있습니다.


## 화자별 대화 스크립트

시작하면 집주인이 파티와 금고실의 보석을 소개합니다.
선수와 보안 전문가의 대화, 복도 현장 조사 시 선수 증언도 대화창으로 표시됩니다.
Enter, Space 또는 E로 한 장씩 넘깁니다. 대화 중에는 이동과 NPC 갱신, 의심도 타이머가 멈춥니다.
대사 원문은 dialogue.py에서 수정할 수 있습니다.
일반 커피를 선수에게 건네도 잠들지는 않습니다. 주방의 요리사에게 빈손으로 말을 걸면 새 커피를 받을 수 있습니다.


## 시작 설정과 준비 시간

시작 화면에서 위·아래 방향키로 난이도 또는 준비 시간을 선택하고
왼쪽·오른쪽 방향키로 변경합니다. 노멀은 180초, 하드는 60초를 기본값으로 합니다.
난이도를 바꾸면 준비 시간도 해당 기본값으로 돌아갑니다.
준비 시간은 30~300초 범위에서 15초 단위로 별도 조정할 수 있습니다.

Enter 또는 Space로 탐정 브리핑을 시작합니다. 준비 타이머는 브리핑과 집주인 환영 대사가
끝나고 직접 움직일 수 있을 때부터 줄어듭니다. 대화, 현장 조사, 수첩, 암호 입력 중에는 멈춥니다.
주인을 칼로 협박하거나 올바른 금고 암호를 입력하면 준비가 조기에 종료됩니다.

시간이 끝나면 추가 도구 획득·조합, 음료 제공, 경보 해제, 사진작가 이동을 할 수 없습니다.
확보한 칼로 주인을 협박하거나 금고 암호를 입력해 범행을 진행할 수 있습니다.
시간 만료 자체로 게임이 끝나지는 않습니다. 결과 화면의 R은 같은 설정으로 새 게임을 시작합니다.
현재 노멀·하드의 차이는 준비 시간 기본값입니다.
